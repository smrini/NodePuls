Component Design Reference

Each section below is one isolated UI piece — shown on its own, not assembled into a page — with the exact CSS values it needs, taken directly from the running v1 app (Dashboard.css, the *.tsx files, and nodepuls.svg). Build each as its own Vue SFC per NodePuls-Code-Guidelines.md's file structure; the "maps to" line under each heading names the target file.

Motion

feeds assets/main.css
Keyframe Duration Where
pulse (1 → 0.5 → 1) 2s infinite Connection dot, checking status icon
dropdownSlide 0.2s ease Device dropdown opening
slideDown 0.2s ease-out Website card expanding
formSlideIn 0.4s cubic-bezier(0.16,1,0.3,1) Add-website form appearing
Logo gradient sweep 2s infinite Logo "puls" text
Logo/tagline opacity pulses 1.5s / 2s infinite Logo text

No page-load entrance animation anywhere — motion only ever responds to something happening. Keep that rule in v2.

16 — Reference

Tokens (CSS)

canonical assets/base.css 
:root {
  /* surfaces */
  --bg0: #0f172a; --bg1: #1e293b; --bg2: #334155; --border1: #475569;

  /* text */
  --t3: #64748b; --t2: #94a3b8; --t1: #cbd5e1; --t-bright: #e2e8f0; --t-max: #f8fafc;

  /* accent */
  --ac-light: #60a5fa; --ac: #3b82f6; --ac-strong: #2563eb;

  /* status */
  --ok: #22c55e; --warn: #f59e0b; --danger: #ef4444;

  /* chart-only — do not alias to --ok */
  --chart-cpu: #3b82f6; --chart-mem: #10b981;
  --chart-download: #f59e0b; --chart-upload: #ef4444;
  --chart-grid: #374151; --chart-axis: #9ca3af; --chart-tooltip-bg: #1f2937;

  /* radius */
  --r-icon: 4px; --r-btn: 6px; --r-card: 8px; --r-panel: 12px;

  /* fonts */
  --sans: -apple-system, BlinkMacSystemFont, "Segoe UI", "Roboto", sans-serif;
  --mono: "Monaco", "Menlo", "Ubuntu Mono", monospace;
}
